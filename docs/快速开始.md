# 快速开始

## Ubuntu

### 1. 安装系统依赖（需要密码，一次性）

```bash
sudo apt install -y libxcb-cursor0 libxcb-icccm4 libxcb-image0 libxcb-keysyms1 libxcb-randr0 libxcb-render-util0 libxcb-shape0 libxcb-xinerama0 libxcb-xkb1 libxkbcommon-x11-0 libportaudio2
```

### 2. 创建虚拟环境并安装 Python 依赖

```bash
python3 -m venv .venv
```

```bash
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

### 3. 运行

```bash
python3 main.py
```

### 4. 打包成软件（可选）

```bash
./scripts/build_linux.sh
```

产物在 `dist/NoiseDefense/NoiseDefense`，运行前确保已执行第 1 步。

---

## Windows

### 1. 创建虚拟环境并安装依赖

```powershell
python -m venv .venv
```

```powershell
.\.venv\Scripts\Activate.ps1
```

```powershell
pip install -r requirements.txt
```

### 2. 运行

```powershell
python main.py
```

### 3. 打包成 exe

```powershell
./scripts/build_windows.ps1
```

产物在 `dist\NoiseDefense.exe`，双击运行。Windows 无需安装系统依赖。

---

## 常见问题

- 运行报 `PortAudio library not found`：回到 Ubuntu 第 1 步，`libportaudio2` 没装上。
- 运行报 Qt 平台插件错误（xcb-cursor0）：回到 Ubuntu 第 1 步，整条命令重装一次。
- 测试：`env -u PYTHONPATH .venv/bin/python -m pytest tests/`
